### 3. Функція зі змінною кількістю аргументів

```python
def average_temperature(*temperatures: float) -> float:
    """Обчислює середню температуру з довільної кількості значень."""
    if not temperatures:
        return 0
    return sum(temperatures) / len(temperatures)
```

### 5. Рекурсивна функція

```python
def find_temperature_range(data: list, start: int, end: int) -> tuple[float, float]:
    """Рекурсивно знаходить мінімальну та максимальну температуру."""
    if start == end:
        temp = data[start]['temperature']
        return (temp, temp)
    mid = (start + end) // 2
    left_min, left_max = find_temperature_range(data, start, mid)
    right_min, right_max = find_temperature_range(data, mid + 1, end)
    return (min(left_min, right_min), max(left_max, right_max))
```

### 6. Функція вищого порядку та `map`

Функція `apply_to_temperature_data` приймає іншу функцію (`func`) як аргумент. У головній програмі ми можемо використати `map` для схожої задачі.

```python
def apply_to_temperature_data(data: list, func: callable) -> list:
    """Застосовує задану функцію до температурних даних."""
    return [{**item, 'temperature': func(item['temperature'])} for item in data]

# Приклад використання map для отримання списку температур
temperatures = list(map(lambda day: day['temperature'], weather_data))
```
